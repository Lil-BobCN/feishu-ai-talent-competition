业务扩域循环：从首个试点结果到分阶段蓝图的建议性设计

价格试点形成可参考结果后，怎样与企业共同判断下一步扩向哪里、为什么值得扩，以及如何逐步放大经营价值和治理效能——这是 03 业务扩域循环要回答的问题。03 由人主导：它不是自动运行的业务系统、评分制度或实施合同，而是一份建议性蓝图。扩域选择与实施路径均为建议，最终由企业确认、调整、暂缓或否决。本报告不虚构实施合同和试验结果，真实痛点、数据可得性与内部优先级全部待企业核验。

§3 · 五步法与角色分工

FDE 不替企业拍板

五步共创手段，四方各就各位；信息不足时，可以建议暂缓。

3.1 五步共创手段

步骤共创手段
第一步与管理层沟通经营目标和治理诉求
第二步与候选业务域负责人及一线人员核验真实痛点
第三步共同复查首个试点的结果、已有能力和未解决问题
第四步结合企业资料，用简要情景推演讨论候选场景的数据、协作和风险
第五步形成分阶段扩域建议，由企业选择采纳、调整或暂缓

3.2 四方角色分工

角色分工
企业管理层提供经营方向
候选业务域负责人 · 一线人员核验真实痛点与现实做法
IT · 数据 · 安全团队说明可行性与约束
FDE · 方案团队负责资料分析、能力盘点和建议整理——不替企业拍板；没有明确业务负责人或关键信息不足时，可以建议暂缓

这对企业意味着什么。扩域讨论不是方案团队单方面“交方案”：方向来自管理层，现实来自一线，约束来自 IT 与数据安全，FDE 只负责把资料、能力和建议整理清楚——决定权始终在企业手里。

§4 · 判断维度

先价值，后能力

先问值不值得，再问能不能——不打分、不设阈值、不定强制规则。

次序建议关注的维度
先关注场景能否创造重要经营价值、改善跨部门协同或提升治理效能
再讨论已有能力可以复用多少、还需补充哪些数据与能力、风险是否可控

上述内容用于帮助企业讨论，不形成分数、权重、固定阈值或强制选择规则。本方案设计判断

为什么是先价值后能力。先看能力容易把扩域讨论变成“现有工具能做什么就做什么”；先看价值，才能把讨论锚在经营问题上，再回头清点已有能力够不够用。

§5 · 候选场景

三个建议，等待企业的答案

顺序为方案推断，不是圣农批准的路线——每行标注三级证据状态。

事实边界先行：官方赛题披露零售业务覆盖多区域、多人员和多渠道，相关数据分散在多个系统；2025 年年报提出精准预测、高效生产、精益仓储、智能物流、产销协同、全渠道策略和 B 端客户全周期管理等方向。圣农公开事实这些方向说明价格试点之后可以优先讨论渠道、库存、促销和履约等相邻场景，但不能证明企业已经存在某个具体异常。本方案设计判断真实痛点、数据可得性、业务负责人、资源投入、优先顺序和试点价值，均需结合企业内部信息共同确认。待企业验证

§6 · 案例构思

一个说明性情景

用来说明“试点形成的对象和经验怎样支持相邻场景讨论”——不是已发现的经营异常。

⚠ 案例构思（说明性情景，非圣农经营异常）：假设某区域产品在价格或促销策略执行后，经销商进货量增加，但终端动销没有同步变化——企业可以进一步核验这是正常备货，还是值得关注的产销协同问题。该情景只用于说明“价格试点形成的对象和经验怎样支持相邻场景讨论”，不是已经发现的圣农经营异常；正常备货、季节性储备和其他合法经营安排都需要保留。本方案设计判断

这个情景刻意停在“值得核验”而不是“已经异常”：与 01 的候选异常信号同理，扩域讨论的起点是证据边界清楚的疑问，不是预设结论。本方案设计判断

§7 · 分阶段建议

不设时间表的路带

按证据成熟度和业务邻近程度排列——不承诺企业一定按此顺序实施。

第一阶段建议：渠道库存与动销协同
后续相邻阶段：根据真实结果，再讨论促销毛利治理或 B 端履约治理
远期探索方向：生产、仓储物流、采购、养殖育种或海外业务

以上按现有证据成熟度和业务邻近程度排列，不设置具体时间表，也不承诺企业一定按此顺序实施；每完成一个真实试点，都可以回到 03 重新讨论下一阶段建议。本方案设计判断

§8 · 跨循环边界

03 不改变已确认的分工

新场景回到 01 独立成案，可控问题回到 02 能力进化——03 只提供建议。

边界规则
新场景仍走 01企业采纳某个新场景后，建议先把它作为独立业务域的小范围试点；其中的新经营事件仍按 01 建立独立事件、案件和 Agent 上下文——不让价格案件直接切换成库存或履约 Skill（机制见 01 报告）
可控问题仍走 02真实案件关闭后，如果暴露的是 Agent 接案后可控的 Skill、Prompt、MCP 或工作流问题，再按 02 进入能力进化（机制见 02 报告）
03 只提供建议不直接修改生产能力，不执行真实审批，也不承担扩域项目管理

这对企业意味着什么。采纳一个新场景不等于买一套新系统：调查、决策、执行与验证仍然走 01 已经确认的闭环，能力改进仍然走 02 已经确认的进化链——03 只是决定“下一步去哪”的那张地图。
