# 圣农经营智能中枢｜证据与参考资料索引

> 用途：为 01、02 评委文案提供可下钻的来源、事实状态和边界说明。
> 阅读方式：每条重要主张都应落在五类事实状态之一；可追溯不等于已经落地，本索引同时说明每个来源目前不能证明什么。

## 1. 先读这张表

评委材料里的每条重要主张，都应落在以下五类事实状态之一：

| 状态 | 在评委材料中的含义 |
|---|---|
| `圣农公开事实` | 来自年报、官方赛题或企业公开材料；只能证明公开披露的范围。 |
| `行业验证经验` | 来自行业案例或路线参考；用于说明方法有先例，不证明圣农已经采用。 |
| `官方技术依据` | 来自平台官方文档、固定代码或可复现实验；只能证明通用能力或限制。 |
| `本方案设计判断` | 本项目根据问题、证据和边界形成的设计选择；不等于企业现状。 |
| `待企业验证` | 需要圣农真实字段、接口、权限、组织、租户、样本或 E2E 才能确认。 |

`verified / partial / designed / simulated / unknown / unsupported` 是能力状态，不是企业事实等级。两者不能互相替代。

## 7. 评委下钻路径

1. 先读 [01 经营事件循环评委文案](./01_经营事件循环_评委文案.md)，理解企业问题、主链和模拟案件。
2. 对公开事实追溯到本索引第 2 节；对语义层、失败处理和数据合同追溯到第 3—4 节。
3. 再读 [02 能力进化循环评委文案](./02_能力进化循环_评委文案.md)，理解一次案件关闭后能力如何经过现实检验进化。
